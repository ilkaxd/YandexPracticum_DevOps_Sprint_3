## Задание

- Создать bash скрипт `/opt/script.sh` со следующим содержимым:

```bash
while true; do
  date >> /opt/my.log
  sleep 1
done
```

- Запустить `/opt/script.sh` отдельным процессом

- Удалить `/opt/script.sh`

- Убедиться что процесс продолжает выполняться

- Найти и задокументировать способ обнаружить в системе исходный код скрипта, который выполняется, но был удалён

## Решение

Для обнаружения кода запущенного скрипта необходимо:

- запустить скрипт отдельным процессом (например в фоне):

```bash
/bin/sh /opt/script.sh  &
```

В результате вернётся PID процесса, но его можно узнать и позже

- удалить файл:

```bash
rm /opt/script.sh
```

- определить PID процесса:

```bash
ps -U ${USER} -o pid,command,state | grep script.sh

9349 /bin/sh /opt/script.sh S
```

В данном случае он равен 9349

- посмотреть его файловые дескрипторы:

```bash
ls -la /proc/9349/fd/

...
bash 9349 ilkaxd 254r REG 252,0 52 393823 /opt/script.sh (deleted)
...
```

- посмотреть содержимое файлового дескриптора:

```bash
cat /proc/9349/fd/254 > /opt/script_removed.sh
```
